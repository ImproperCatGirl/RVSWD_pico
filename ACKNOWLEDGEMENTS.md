# Acknowledgements

The RVSWD protocol implementation in this repository builds on prior work from:

- [aappleby/picorvd](https://github.com/aappleby/picorvd), a Raspberry Pi Pico
  debugger for WCH CH32V devices using the SWIO debug interface.
- [Nicolai-Electronics/esp32-component-rvswd](https://github.com/Nicolai-Electronics/esp32-component-rvswd),
  an ESP-IDF RVSWD programmer component for WCH CH32 microcontrollers.

Those projects documented and implemented the WCH debug protocols that informed
the bit-banged and PIO RVSWD code here. See the upstream repositories for their
license terms and original source history.
